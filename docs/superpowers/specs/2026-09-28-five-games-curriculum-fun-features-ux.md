## 0. 구성과 사용법

게임 1종을 다섯 부분으로 적는다.

| 부분 | 답하는 질문 | 누가 쓰는가 |
|------|-------------|-------------|
| 교육과정 근거 | 이 게임은 무엇을 가르치기로 약속했는가 | 교사 검토, 납품 근거 |
| 핵심 재미 | 왜 아이가 계속 하는가 | 기획 판단 기준 |
| 주요 플레이 기능 | 무엇을 만들어야 하는가 | 개발 범위·견적 |
| UX 플로우 | 어떤 순서로 겪고, 화면에 무엇이 있는가 | 화면 설계, QA 시나리오 |
| 시안 확인 | 방향성 시안에서 가져갈 것과 고칠 것 | 아트 담당 |

**우선순위.** P0 = 없으면 게임이 성립하지 않음. P1 = 핵심 재미를 완성함. P2 = 여유가 있으면.

**성취기준 표기.** 성취기준 원문은 검증 보고서 1장에 모았다. 이 문서의 표에는 원문 요지만 적는다. 원문은 2차 전사본과 검색 결과로 확인했으므로 납품 전에 교육부 고시 원문과 한 번 더 대조한다(열린 항목 O-1).

**검증 번호.** 표 안의 `03-1`, `05-6` 같은 번호는 검증 보고서의 항목 번호다.

## 1. 변경 기록과 남은 결정

**요약.** v1.1의 원칙은 두 가지다. 모든 개념은 교육과정 안에서만 다룬다. 한국사는 5학년 2학기에, 6·25 전쟁 이후 민주화와 경제 성장은 6학년 1학기에 배운다. 이에 따라 05는 교과 밖인 직렬·병렬 전략을 빼고 "탑마다 하나의 전기 회로"로 다시 짰다. 검증 보고서의 치명 17건, 중요 25건, 보완 12건을 모두 반영했다. 남은 결정은 4건이다.

## 2. 공통 사양

### 2.1 제작 조건

| 항목 | 값 |
|------|-----|
| 교과 범위 | 모든 개념은 해당 학년까지 배운 교육과정 안에서만 다룬다. 교과 밖 개념은 규칙·문구·퀴즈·연출 어디에도 쓰지 않는다. 유물·별자리·사례는 사용 교과서에 실린 것에서 고른다 |
| 용어 표기 | 교과서 표기로 통일: 4·19 혁명, 5·16 군사 정변, 5·18 민주화 운동, 6월 민주 항쟁, 3·15 부정 선거, 8·15 광복, 6·25 전쟁, 정전 협정, 전기 회로, 직렬연결, 전자석 |
| 배포 | 게임 1종 = HTML 파일 1개. 정적 호스팅(학교 홈페이지·GitHub Pages·드라이브 공개 링크)의 URL로 연다 |
| 네트워크 | 외부 요청 0건. 그래픽·사운드는 파일 안에 인라인(base64·SVG) |
| 파일 크기 | 03·05·14는 1MB 이하. 08·16은 8MB 이하 |
| 서버·개인정보 | 백엔드·계정·랭킹 없음. 학생 입력 0개. 저장은 localStorage만 |
| 한 판 | 20~40분 |
| 화면 | 태블릿 가로 1024×768 기준. 데스크톱은 확대 대응 |
| 입력 | 마우스·터치·키보드 동시 지원. 드래그는 Pointer Events로 직접 구현, 드래그 영역 `touch-action:none`. 방향키 게임은 화면 가상 패드 병행. 최소 히트박스 44px |
| 콘텐츠 분리 | 문항·대사·라벨·해금 플래그는 파일 상단 CONTENT 블록에만 둔다 |

**유물 규칙.** 모든 유물은 사용 교과서에 실린 것만 쓴다. 교과서에 없으면 같은 시대의 교과서 유물로 바꾼다. 특히 철제 칼·철제 화살촉·고분 벽화 속 그림·거북선 함포는 교과서 사진으로 확인한다(열린 항목 O-4). 훈민정음과 측우기는 조선 전기 문화유산으로 감정 문항에 쓰고, 유교 문화의 영향은 기믹 방이 맡는다.

**학습 목표.** 게임을 마친 학생은 다음을 할 수 있다.
1. 유물을 보고 어느 시대의 것인지 말한다.
2. 유물을 보고 그 시대 사람들이 어떻게 살았고 무엇을 생각했는지 추론한다.
3. 도구와 기술이 시대에 따라 달라진 순서를 말한다.

**학습이 붙는 두 자리.** 기믹 방은 "그 시대에는 이렇게 살았다"를 손으로 해 보는 자리다. 감정소는 "이 유물로 그 시대를 읽는다"를 머리로 해 보는 자리다. 성취기준의 동사 "추론한다"에 맞춰 감정 문항은 모두 추론형이다. 전투는 학습을 싣지 않고 재미를 책임진다(결정 7).

### 3.2 핵심 재미

**한 줄.** 층마다 시대가 바뀌는 던전에서, 그 시대 유물의 힘을 빌려 싸우고 모으며 강해진다.

**플레이어의 환상.** "나는 밤의 박물관을 탐험하는 유물 탐험가다. 유물을 지키며, 그 시대의 기술을 빌려 쓴다."

| 재미의 층 | 무엇이 재미인가 | 만드는 장치 |
|-----------|-----------------|-------------|
| 손 | 조작 부담 없는 확실한 타격감 | 자동 조준 1버튼, 팝 이펙트, 넉백 |
| 선택 | "이번 판은 이렇게 간다"는 빌드 감각 | 유물 3택1, 무기·장신구·도구 조합 |

**절정.** 새 시대의 첫 방이 열리는 순간(층당 1회). 진품으로 감정된 유물로 큰 방을 쓸어버리는 순간. 마지막 층을 나서면 모은 유물이 박물관 진열장에 시대순으로 놓이는 결과 화면.

### 3.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 밤의 박물관 입구. "탐험 시작" 버튼 하나. 저장이 있으면 "이어하기 (3층 입구)"가 먼저 보인다.
2. **첫 30초.** 1층 첫 방. 주먹도끼를 든 채 시작한다. 이동 패드 위에 화살표 하나. 움직이면 화살표가 공격 버튼으로 옮겨 간다. 먼지 유령 2마리가 천천히 다가온다.
3. **첫 유물 (1분).** 적을 지우면 받침대 3개가 솟는다. 첫 선택은 비파형 동검 · 빗살무늬토기 · 반달돌칼로 고정한다. 고르면 설명 카드가 뜬다.
4. **첫 기믹 방 (2~3분).** 불 피우기 순서 스위치. 틀리면 연기만 나고 다시 할 수 있다. 맞히면 방이 밝아지고 유물 하나가 드러난다. 여기까지 모든 조작이 노출된다.
5. **첫 감정소 (4~5분).** "?" 문을 지나면 조용한 감정소. 유물마다 "이 도구로 무엇을 했을까?" 같은 추론 문항 1개. 정답이면 금빛 감정 연출.
6. **첫 큰 전투 방 (5~6분).** 방금 진품이 된 유물로 큰 방을 쓸어버린다. 방을 비우면 계단이 열린다.
7. **층 반복 (1~5층).** 한 층은 아래 "한 층의 흐름"을 따른다. 층당 5~7분.
8. **층 전환.** 계단을 지나면 층 타이틀 카드("4층 · 조선")와 함께 팔레트·적·BGM이 바뀐다. 4층 후반에는 "조선 후기·개항기" 부제 카드가 한 번 더 뜬다. 계단의 방향은 D1에서 정한다.
9. **실패.** 하트 0 → 짧은 암전 → "이 층 입구에서 다시" 카드. 이 층 유물이 흩어지는 연출로 무엇을 잃었는지 보여 준다.
10. **엔딩 (25~35분).** 5층 마지막 방을 나서면 박물관 전시실. 유물이 시대순으로 진열장에 놓인다. 이어서 공통 결과 항목.

**한 층의 흐름.**

```
층 입구(저장) → 전투 방 → 받침대 3택1 → 기믹 방(유물이 드러남) → 전투 방 → 받침대 3택1
           → (전투 방 또는 기믹 방 0~2개) → 감정소(유물마다 1문항)
           → 큰 전투 방(진품의 무대) → 계단 → 다음 층 타이틀 카드
```

**화면 구성.** 좌상 하트 5칸 · 우상 층 진행(n/5) · 좌하 이동 패드 · 우하 공격 버튼, 그 위 도구 버튼 · 감정소 입구는 "?" 문.

### 4.1 교육과정 근거

**쓰지 않는 개념 (교과 밖).** 전구의 직렬·병렬 연결, 전지의 병렬 연결, 코일을 감은 횟수, 전류·전압의 수치, 충전. 이 개념들은 규칙·문구·퀴즈·연출 어디에도 나오지 않는다.

**연출 규칙 (오개념 방지).**
- 회로가 닫히는 순간 전구가 한 번에 켜진다. 빛이 전선을 따라 흘러가다 줄어드는 연출은 쓰지 않는다(05-7).
- 전지 2개를 같은 극끼리 이으면 전구가 켜지지 않는다. 이것은 실제 현상과 같다.
- 전선 비용이나 배치로 병렬을 암시하는 구조를 만들지 않는다. 탑 하나에 회로 하나다.

**학습 목표.**
1. 전지·전선·전구가 끊김 없이 이어져 전구가 전지의 두 극에 연결되어야 불이 켜진다는 것을 안다.
2. 전지 1개일 때와 전지 2개를 직렬연결했을 때 전구 밝기를 비교하고, 직렬연결하는 방법을 안다.
3. 전자석은 전기가 흐를 때만 자석이 되고, 전지를 직렬로 늘리면 세지며, 전지 방향을 바꾸면 극이 바뀐다는 것을 안다.
4. 전기를 아끼고 안전하게 쓰는 방법과 재생에너지마다 조건이 다르다는 것을 안다.

**학습이 붙는 자리.** 탑 하나가 곧 교과서 실험의 전기 회로 하나다. 퀴즈는 "지금 내 탑의 회로도"를 읽는 문제와 안전 점검이다.

### 4.2 핵심 재미

**한 줄.** 전선 두 가닥을 제대로 잇느냐로 탑이 켜지고 꺼지는 기계적 쾌감.

**플레이어의 환상.** "나는 회로판 요새의 전기 기사다. 회로 하나하나가 곧 방어다."

### 4.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 어둠 속 회로판 요새. "전원 켜기" 버튼.
2. **첫 30초.** 첫 전구탑 자리에 전구와 전지 1개. 전구 한쪽 끝에서 +극까지 점선이 보인다. 이어도 아직 켜지지 않는다. 다른 끝에서 −극까지 두 번째 점선이 나타나고, 마저 이으면 전구가 한 번에 켜진다.
3. **1웨이브 (0:30~1:15).** 느린 걷는 구름 몇 마리. 전구탑 하나로 막힌다. 부품이 쌓인다.
4. **첫 준비 시간 (1:15~1:45).** 전지 칸이 반짝인다. 전지를 하나 더 직렬로 넣으면 전구탑이 더 밝아진다. 같은 극끼리 넣으면 꺼지고 "+극과 −극을 이어요" 힌트.
5. **2웨이브 (1:45~2:35).** 첫 나는 구름이 천천히 전선 위로 온다. 경고음과 3초. 탭하면 쫓겨 간다. 이번 한 번은 못 쫓아도 끊지 않는다. 스위치 버튼이 반짝인다. 여기까지 모든 조작이 노출된다.
6. **첫 절단 (3~4웨이브).** 나는 구름이 탑 하나의 전선을 끊는다. 그 탑만 꺼진다. 끊긴 곳을 탭해 수리한다. 이어지는 퀴즈는 "불이 켜지는 회로는 어느 것일까?"
7. **새것의 박자.** 5웨이브 전자석탑·저장 → 6웨이브 첫 안전 점검 → 8웨이브 철 로봇 → 10웨이브 자석 로봇과 극 바꾸기·저장 → 12웨이브 첫 밤 → 14웨이브 구리 로봇 → 15웨이브 풍력·수력·저장 → 18웨이브 모든 적 혼합 → 20웨이브 마지막.
8. **실패.** 코어 하트 0 → 최근 체크포인트의 준비 화면. 회로판은 저장 시점 그대로다.
9. **엔딩 (30~35분).** 20웨이브를 넘기면 모든 탑이 켜진다. 탑별 회로도와 전자석이 쓰이는 예가 뜨고 공통 결과 항목이 이어진다.

**한 웨이브의 흐름.**

```
준비 30초(탑 회로·전지·스위치·극) → 웨이브 시작 → 적 진행 + 나는 구름 1~3회
            (경고 → 쫓기 또는 절단 → 수리) → 웨이브 종료 → 회로도 퀴즈 또는 안전 점검 → 다음 준비
```

**화면 구성.** 좌상 부품 · 상단 가운데 웨이브 n/20 · 우상 코어 하트와 보호막, 배속, 일시정지 · 좌하 건설 메뉴(전구탑·전자석탑·전지) · 탑을 누르면 그 탑의 회로와 스위치·극 버튼이 크게 열린다.

**계절별 대표 별자리.** 그 계절 저녁에 남쪽 하늘에서 잘 보이는 별자리다. 봄 사자·처녀·목동 · 여름 백조·독수리·거문고 · 가을 페가수스·안드로메다·물고기 · 겨울 오리온·큰개·쌍둥이. 편대는 실제 별 배치와 선을 따른다. 최종 목록은 사용 교과서에 실린 별자리로 맞춘다.

**연출 규칙 (오개념 방지).**
- 배경 별의 움직임은 자전에 따른 겉보기 운동이고, 편대의 움직임은 게임 캐릭터의 움직임이다. 두 움직임을 다른 층으로 그리고, 배경 별의 이동 방향은 화면의 방위와 맞춘다(14-3, 14-5).
- 달은 별자리가 아니므로 달 모양 편대를 만들지 않는다.
- 이름은 편대 진입 때 보조로만 보여 준다. 판별의 기준은 "지금 이 하늘에 보이는가"이고, 정답 뒤에는 까닭을 보여 준다(14-8).

**학습 목표.**
1. 하루 동안 태양과 별이 동쪽에서 서쪽으로 움직여 보이는 까닭과 낮과 밤이 생기는 까닭이 지구의 자전임을 안다.
2. 하루 동안 태양 고도가 높아지면 그림자가 짧아지고, 기온은 조금 늦게 가장 높아진다는 것을 안다.
3. 계절마다 저녁 하늘에 보이는 별자리가 다르고, 그 까닭이 지구의 공전임을 안다.
4. 계절에 따라 태양의 남중 고도와 낮의 길이가 달라지고, 계절 변화의 원인이 자전축이 기운 채 공전하기 때문임을 설명한다.

**학습이 붙는 자리.** 판별은 "지금 이 하늘에 보일 편대 고르기" 하나다. 틀려도 손해가 없고, 맞히면 강해지며 까닭을 본다. 개념은 스테이지 조건과 배경 연출이 맡는다.

### 6.2 핵심 재미

**한 줄.** 화면 가득한 별자리 편대를 쓸어버리는 질주감, 그리고 "지금 이 하늘에 뜰 별자리는 저거다"를 알아보는 순간의 짜릿함.

**플레이어의 환상.** "나는 밤하늘 순찰 대원이다. 하늘이 왜 그렇게 보이는지 알면 더 강해진다."

| 재미의 층 | 무엇이 재미인가 | 만드는 장치 |
|-----------|-----------------|-------------|
| 손 | 순수 슈팅 쾌감 | 자동 연사, 별빛 파티클, 화면 흔들림 |
| 알아봄 | 지금 하늘에 뜰 별자리를 알아보는 짜릿함 | 진입 0.5초 슬로우 + 이름 1초, 정답 뒤 공전 다이얼 |
| 성장 | 알아볼수록 강해진다 | 정답 격추 = 무기 단계 +1 (최대 3) |
| 긴장 | 짧은 밤에 정답을 잡아야 한다 | 계절에 따라 교전 시간이 달라짐 |

**절정.** 3단계 무기로 편대 하나를 통째로 별빛 폭발로 지우는 순간. 여름의 짧은 밤에 정답 편대를 아슬아슬하게 잡는 순간. 보스의 "까닭" 문제 3개를 연속으로 맞혀 약점이 모두 열리는 순간.

### 6.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 지평선 위 저녁 하늘과 로켓. "출동" 버튼.
2. **첫 30초.** 기체 아래 화살표 "끌어서 움직이기". 움직이는 순간 자동 연사가 시작되고 구름 편대가 내려온다.
3. **1스테이지 · 하루 (0~5분).** 아침에 태양이 동쪽에서 떠오른다. 한낮에 기체 그림자가 가장 짧아지고, 조금 뒤 기온 막대가 가장 높아진다. 해가 서쪽으로 지면 첫 별자리 편대가 들어온다. 조건 카드 "지금 보이는 별자리".
4. **2스테이지 · 자전 (5~10분).** 별들이 동쪽에서 서쪽으로 움직여 보이고, 북쪽 하늘 별은 북극성 둘레를 돈다. "별이 움직여 보이는 까닭은 지구가 돌기 때문" 한 줄. 조건 "일 년 내내 보이는 별자리".
5. **3스테이지 · 공전 (10~15분).** 조건 카드가 봄 → 여름 → 가을 → 겨울 저녁 하늘로 넘어간다. 정답마다 공전 다이얼.
6. **4스테이지 · 계절 (15~20분).** 시작에 자전축이 기운 지구의 공전 연출. 여름은 태양이 높고 밤이 짧아 정답을 잡을 시간이 적고, 겨울은 길다.
7. **5스테이지 + 보스 (20~28분).** 조건이 섞이고 이름 표시가 0.5초로 줄어든다. 보스의 "까닭" 문제 3연속.
8. **실패.** 하트 0 → 그 스테이지 처음.
9. **엔딩.** 격추한 별자리 하늘 + 공통 항목.

**편대 한 개의 흐름.**

```
편대 진입(슬로우 0.5초, 이름 1초) → 조건 카드와 대조 → 격추 또는 통과
   정답 격추 = 무기 +1, 까닭 다이얼 1초 · 오답 격추 = 점수만 · 정답 놓침 = 스테이지 후반 재등장
```

**화면 구성.** 가로 화면 가운데에 세로 교전 영역, 아래에 지평선과 방위. 왼쪽 여백에 하트와 무기 단계, 오른쪽 여백에 조건 카드·까닭 다이얼·점수.

3. (에필로그 해금 후) 분단이 남긴 이산가족의 아픔을 알고, 통일 이후의 여러 상황과 바람직한 모습을 말한다.

**학습이 붙는 자리.** 정답이 없는 생활 선택이다. 1장에서 지킨 우리말이 광복 장면에서 돌아오고, 2장에서 챙긴 물건이 3장에서 쓰인다. 퀴즈는 없다(D2).

**표현 규칙 (오개념 방지).**
- 1953년은 "전쟁이 끝났다"가 아니라 "정전 협정을 맺었다"로 쓴다(16-1).

6. **닫는 장면.** 할머니가 사진첩을 덮으며 한 줄. 해금 플래그가 켜져 있으면 에필로그로 이어진다.
7. **결과.** 완성된 사진첩을 처음부터 넘겨 본다. 마지막 장에 공통 항목.

**장면 한 개의 흐름.**

```
빈 사진 칸 탭 → 수채 장면 → 대사 → 선택(잠김 최대 1) → 가족 초상·게이지 변화
            → 흰 사진이 세피아로 인화 → 사진첩 칸이 채워짐
```

**화면 구성.** 왼쪽 주인공 · 가운데 사진(장면) · 아래 선택지·물건 카드 3장(손글씨 느낌) · 좌상 가족 초상 5인과 수치 3줄 · 우상 설정·사진첩 버튼.

### 7.5 시안 확인
