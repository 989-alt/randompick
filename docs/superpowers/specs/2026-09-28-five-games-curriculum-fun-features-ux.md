## 0. 구성과 사용법

게임 1종을 다섯 부분으로 적는다.

| 부분 | 답하는 질문 | 누가 쓰는가 |
|------|-------------|-------------|
| 교육과정 근거 | 이 게임은 무엇을 가르치기로 약속했는가 | 교사 검토, 납품 근거 |
| 핵심 재미 | 왜 아이가 계속 하는가 | 기획 판단 기준 |
| 주요 플레이 기능 | 무엇을 만들어야 하는가 | 개발 범위·견적 |
| UX 플로우 | 어떤 순서로 겪고, 화면에 무엇이 있는가 | 화면 설계, QA 시나리오 |
| 시안 확인 | 방향성 시안에서 가져갈 것과 고칠 것 | 아트 담당 |

**우선순위.** P0 = 없으면 게임이 성립하지 않음. P1 = 핵심 재미를 완성함. P2 = 여유가 있으면.

**성취기준 표기.** 단원명과 성취기준 코드·요지는 보드 원문을 그대로 옮겼다. 납품 전에 교육과정 원문과 한 번 더 대조한다(열린 항목 O-1).

## 2. 공통 사양

### 2.1 제작 조건 (보드 v1.1)

| 항목 | 값 |
|------|-----|
| 배포 | 게임 1종 = HTML 파일 1개. 정적 호스팅(학교 홈페이지·GitHub Pages·드라이브 공개 링크)의 URL로 연다. 태블릿에서 file:// 열기와 그때의 localStorage가 불안정하기 때문 |
| 네트워크 | 외부 요청 0건. 그래픽·사운드는 파일 안에 인라인(base64·SVG) |
| 파일 크기 | 03·05·14는 1MB 이하(아케이드·시뮬 계열). 08·16은 8MB 이하(일러스트 계열). 외부 라이브러리는 인라인만 |
| 서버·개인정보 | 백엔드·계정·랭킹 없음. 이름·학번 등 학생 입력 0개. 저장은 localStorage만 |
| 한 판 | 20~40분 |
| 화면 | 태블릿 가로 1024×768 기준. 데스크톱은 확대 대응 |
| 입력 | 마우스·터치·키보드 동시 지원. 드래그는 Pointer Events로 직접 구현(HTML5 Drag&Drop 금지), 드래그 영역 `touch-action:none`. 방향키 게임은 화면 가상 패드 병행. 최소 히트박스 44px |
| 콘텐츠 분리 | 문항·대사·라벨·해금 플래그는 파일 상단 CONTENT 블록에만 둔다. 교사가 열어 고칠 수 있게 |
| 튜토리얼 | 없음. 첫 30초 안에 조작 1개를 화살표로 유도, 3분 안에 모든 조작을 노출 |
| 퀴즈 | 벽이 아니라 파워업. 오답도 진행. 틀린 문제는 같은 판에서 2~3회 재출제. 한 판 15~30문항. 읽어야 하는 문제는 정지 구간으로 분리 |
| 정확성 | 게임 규칙이 교과서 개념과 어긋나면 안 된다. 장르 관습과 충돌하면 관습을 버린다. 수치는 초등 범위 |
| 톤 | 밝고 안전, 폭력·공포 없음. 08·16은 생활사 중심으로 무게를 조절 |

### 2.2 공통 화면 흐름

```
[S0 타이틀] → [S1 이어하기 확인] → [S2 본 플레이] ⇄ [S3 오버레이: 퀴즈·판별]
                                        │  체크포인트마다 [S4 저장 토스트]
                                        ▼
                                   [S5 결과 화면] → S0
```

| 화면 | 역할 | 넘어가는 조건 |
|------|------|---------------|
| S0 타이틀 | 시작 버튼 하나와 배경 연출 | 탭 |
| S1 이어하기 확인 | 저장이 있을 때만. "이어하기 / 처음부터" | 선택 |
| S2 본 플레이 | 게임마다 다름 (3~7장) | 완주 |
| S3 오버레이 | 퀴즈·판별. 본 플레이를 덮되 뒤 장면을 흐리게 남긴다 | 응답 |
| S4 저장 토스트 | 우상단 1.5초. 조작을 막지 않는다 | 자동 |
| S5 결과 화면 | 공통 5항목 + 게임별 1항목 | 다시하기 / 타이틀 |

**결과 화면 공통 5항목.** 플레이 시간 · 도달 지점 · 정답률 · 틀린 문제 다시 보기 · 다시하기.

**학습 목표.** 게임을 마친 학생은 다음을 할 수 있다.
1. 유물을 보고 어느 시대의 것인지 말한다.
2. 유물을 보고 그 시대 사람들이 어떻게 살았는지 추론한다.

**학습이 붙는 두 자리.** 기믹 방은 "그 시대에는 이렇게 살았다"를 손으로 해 보는 자리다. 감정소는 "이 유물로 그 시대를 읽는다"를 머리로 해 보는 자리다. 전투는 학습을 싣지 않고 재미를 책임진다(결정 7).

### 3.2 핵심 재미

**한 줄.** 층마다 시대가 바뀌는 던전에서, 그 시대의 유물을 무기로 삼아 싸우고 모으며 강해진다.

**플레이어의 환상.** "나는 밤의 박물관을 탐험하는 유물 탐험가다. 손에 든 무기가 곧 그 시대의 기술이다." (C5)

| 선택 | "이번 판은 이렇게 간다"는 빌드 감각 | 유물 3택1, 무기·장신구·도구 조합 |
| 발견 | 다음 층에 무엇이 있을지 기대 | 층마다 팔레트·적·BGM·무기가 통째로 바뀜 |
| 앎 | 아는 만큼 강해진다 | 퀴즈 정답 = 진품 감정 = 강화 |

**절정.** 새 시대의 첫 방이 열리는 순간(층당 1회). 진품으로 감정된 무기로 큰 방을 쓸어버리는 순간. 마지막 층을 나서면 모은 유물이 박물관 진열장에 시대순으로 놓이는 결과 화면.

### 3.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 밤의 박물관 입구. "탐험 시작" 버튼 하나. 저장이 있으면 "이어하기 (3층 입구)"가 먼저 보인다.
2. **첫 30초.** 1층 첫 방. 주먹도끼를 든 채 시작한다. 이동 패드 위에 화살표 하나. 움직이면 화살표가 공격 버튼으로 옮겨 간다. 먼지 유령 2마리가 천천히 다가온다.
3. **첫 유물 (1분).** 적을 지우면 받침대 3개가 솟는다. 첫 선택은 비파형 동검(무기) · 빗살무늬토기(장신구) · 반달돌칼(도구)로 고정해 세 종류를 한 번에 보여 준다.
4. **첫 기믹 방 (2~3분).** 불 피우기 순서 스위치. 틀린 순서로 밟으면 연기만 나고 다시 할 수 있다. 맞히면 방이 밝아지고 유물 하나가 드러난다. 여기까지 이동·공격·밟기·도구 버튼이 모두 노출된다.
5. **첫 감정소 (4~5분).** "?" 문을 지나면 조용한 감정소. 지금까지 얻은 유물이 받침대 위에 놓인다. 유물마다 "이 도구로 무엇을 했을까?" 같은 3지선다 1문항. 정답이면 금빛 감정 연출.
6. **첫 큰 전투 방 (5~6분).** 방금 진품이 된 무기로 큰 방을 쓸어버린다. 방을 비우면 계단이 열린다.
7. **층 반복 (1~5층).** 한 층은 아래 "한 층의 흐름"을 따른다. 층당 5~7분.
8. **층 전환.** 계단을 지나면 층 타이틀 카드("3층 · 고려")와 함께 팔레트·적·BGM이 바뀐다. 층 입구 저장 토스트. 계단의 방향은 D1에서 정한다.
9. **실패.** 하트 0 → 짧은 암전 → "이 층 입구에서 다시" 카드. 이 층 유물이 흩어지는 연출로 무엇을 잃었는지 보여 준다.
10. **엔딩 (25~35분).** 5층 마지막 방을 나서면 박물관 전시실. 유물이 시대순으로 진열장에 날아가 놓인다. 이어서 공통 결과 항목.

**한 층의 흐름.**

```
층 입구(저장) → 전투 방 → 받침대 3택1 → 기믹 방(유물이 드러남) → 전투 방 → 받침대 3택1
           → (전투 방 또는 기믹 방 0~2개) → 감정소(유물마다 1문항)
           → 큰 전투 방(진품 무기의 무대) → 계단 → 다음 층 타이틀 카드
```

**화면 구성.** 좌상 하트 5칸 · 우상 층 진행(n/5) · 좌하 이동 패드 · 우하 공격 버튼, 그 위 도구 버튼 · 감정소 입구는 "?" 문.

**학습 목표.**
1. 전지·전선·전구가 끊김 없는 고리로 이어져야 전기가 흐른다는 것을 안다.
2. 직렬과 병렬 연결의 차이를 밝기와 끊김의 결과로 설명한다.
3. 전자석은 전기가 흐를 때만 자석이 되고, 코일을 더 감거나 전지를 직렬로 늘리면 세진다는 것을 안다.
4. 필요 없는 전기를 끄면 에너지를 아낄 수 있고, 발전 방식마다 조건이 다르다는 것을 안다.

**학습이 붙는 자리.** 배선 자체가 학습이다. 퀴즈는 별도 지식 문제가 아니라 "방금 내가 만든 요새의 회로도"를 읽는 문제다.

### 4.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 어둠 속 회로판 요새. "전원 켜기" 버튼.
2. **첫 30초.** +단자 → 전구탑 → −단자를 잇는 점선 가이드 하나. 따라 그어 고리가 닫히는 순간 전구탑이 켜지고 네온이 흐른다. 가이드는 이 한 번뿐이다.
3. **1웨이브 (0:30~1:15).** 느린 걷는 구름 몇 마리. 전구탑 하나로 막힌다.
4. **첫 준비 시간 (1:15~1:45).** 발전소의 전지 슬롯이 반짝인다. 전지를 세로로 쌓으면 전구탑이 더 밝아진다.
5. **2웨이브 (1:45~2:35).** 첫 나는 구름이 천천히 전선 위로 온다. 경고음과 3초. 탭하면 쫓겨 간다. 이번 한 번은 못 쫓아도 끊지 않고 날아간다. 여기까지 드래그·탭·전지 조작이 모두 노출된다.
6. **첫 직렬 (3웨이브).** 에너지가 모자라 두 번째 타워를 같은 고리에 끼운다. 두 타워의 빛이 함께 약해진다(R1).
7. **첫 절단 (4웨이브).** 나는 구름이 직렬 고리를 끊는다. 그 고리의 타워가 한꺼번에 꺼진다. 끊긴 곳을 탭해 수리한다. 이어지는 퀴즈는 "어디가 끊겼기에 둘 다 꺼졌을까?"
8. **새것의 박자.** 5웨이브 전자석탑 해금·저장 → 8웨이브 금속 로봇 → 10웨이브 대규모 절단·저장 → 12웨이브 첫 밤 → 15웨이브 풍력·수력·저장 → 18웨이브 모든 적 혼합 → 20웨이브 마지막.
9. **실패.** 코어 하트 0 → 최근 체크포인트의 준비 화면. 회로판은 저장 시점 그대로다.
10. **엔딩 (30~35분).** 20웨이브를 넘기면 요새 전체가 한 번에 켜진다. 회로판 스냅샷과 회로도가 나란히 뜨고 공통 결과 항목이 이어진다.

**한 웨이브의 흐름.**

```
준비 30초(고리·전지·스위치) → 웨이브 시작 → 걷는 구름 진행 + 나는 구름 1~3회
            (경고 → 쫓기 또는 절단 → 수리) → 웨이브 종료 → 회로도 퀴즈 1문항 → 다음 준비
```

**화면 구성 (시안 기준).** 좌상 에너지 · 상단 가운데 웨이브 n/20 · 우상 코어 하트, 배속, 일시정지 · 좌하 건설 메뉴(전구탑·전자석탑·전지·스위치) · 판 위에 발전소와 +·− 단자.

**교과서 단원 (보드 원문).** 사회 5-2 「3 식민 통치와 저항, 전쟁이 바꾼 사회와 생활」 + 6-1 「1-① 평화 통일」 + 도덕 6 「05 통일 한반도의 어느 날」.

| 코드 | 보드 요지 | 장 | 게임 안의 자리 |
|------|-----------|----|----------------|
| 6사06-01 | 식민 통치와 저항이 생활에 미친 영향 | 1장 (1940년대 초~1945) | 학교에서 쓰는 말, 이름을 적는 방식, 공출, 광복의 날 |
| 6사06-02 | 광복과 6·25가 생활에 미친 영향 | 2·3장 (1950, 1953) | 피란 보따리, 피란 기차, 헤어짐, 돌아온 마을, 마지막 가족 사진 |
| 6사07-01 | 분단과 평화 통일 | 에필로그 (해금) | 이산가족 |
| 6도03-03 | 통일 이후 사회 탐구 | 에필로그 (해금) | 통일 한반도의 어느 날 |

**학습 목표.**
1. 일제가 우리말과 이름을 빼앗고 물자를 거둬 간 일이 보통 사람의 생활을 어떻게 바꿨는지 말한다.
2. 광복과 6·25 전쟁이 한 가족의 삶에 남긴 영향을 말한다.
3. (에필로그 해금 후) 분단이 남긴 이산가족의 아픔과 통일 이후의 생활을 상상해 말한다.

**학습이 붙는 자리.** 정답이 없는 생활 선택이다. 1장에서 지킨 우리말이 광복 장면에서 돌아오고, 2장에서 챙긴 물건이 3장에서 쓰인다. 퀴즈는 없다(D2).

### 7.2 핵심 재미

**한 줄.** 할머니의 어린 시절을 사진 한 장씩 채워 가며, 그 시대의 생활 선택으로 우리 가족을 지킨다.

**플레이어의 환상.** "나는 1930년대에 태어난 아이다. 큰일은 내가 막을 수 없지만, 오늘 무엇을 챙기고 누구 손을 잡을지는 내가 정한다."

| 재미의 층 | 무엇이 재미인가 | 만드는 장치 |
|-----------|-----------------|-------------|
| 수집 | 앨범이 한 장씩 채워지는 만족 | 흰 사진이 세피아로 인화됨 |
| 무게 | 작은 선택이 가족을 바꾼다 | 가족 5인의 상태, 게이지 |
| 페이오프 | 챙긴 물건, 지킨 말이 돌아온다 | 보따리 물건 사용, 광복의 우리말 노래 |
| 여운 | 마지막 사진에 누가 있는가 | 1953 가족 사진 = 이 판의 요약 |

**절정.** 광복의 날, 세피아 사진에 처음 색이 드는 순간. 보따리에 챙긴 물건이 꼭 필요한 순간에 나오는 순간. 1953 마지막 가족 사진.

### 7.4 UX 플로우

**한 판 흐름.**

1. **타이틀 (0:00).** 등잔불 아래 펼친 사진첩(썸네일). "사진첩 열기" 버튼.
2. **첫 30초.** 첫 장의 빈 사진 칸 하나가 반짝이고 화살표가 가리킨다. 탭하면 장면이 열린다.
3. **1장 · 1940년대 초~1945 (0~9분).** 7장면. 놀이·장날 같은 밝은 장면 사이에 학교에서 쓰는 말, 이름, 공출 선택. 장면마다 사진이 인화된다. 광복의 날에 우리말이 높으면 우리말 노래와 함께 첫 색이 든다.
4. **2장 · 1950 (9~18분).** 7장면. 피란 보따리 3칸 고르기 → 피란 기차 → 헤어짐. 잠긴 선택지를 만난다.
5. **3장 · 1953 (18~26분).** 7장면. 돌아온 마을. 보따리 물건이 쓰인다. 마지막 가족 사진.
6. **닫는 장면.** 할머니가 사진첩을 덮으며 한 줄(R6). 해금 플래그가 켜져 있으면 에필로그로 이어진다: 이산가족 → 통일 한반도의 어느 날.
7. **결과.** 완성된 사진첩을 처음부터 넘겨 본다. 마지막 장에 공통 항목.

**장면 한 개의 흐름.**

```
빈 사진 칸 탭 → 수채 장면 → 대사 → 선택(잠김 최대 1) → 가족 초상·게이지 변화
            → 흰 사진이 세피아로 인화 → 사진첩 칸이 채워짐
```

**화면 구성 (시안 기준).** 왼쪽 주인공 · 가운데 사진(장면) · 아래 선택지·물건 카드 3장(손글씨 느낌) · 좌상 가족 초상 5인과 수치 3줄 · 우상 설정·사진첩 버튼.
